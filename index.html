¿Por qué programamos?

Programar es darle instrucciones a la computadora para que haga cosas por nosotros. ¡Es como ser el jefe de la computadora! 🤖

✅ Con programación podemos hacer juegos, aplicaciones, dibujos automáticos, calculadoras, y muchas cosas más. ¡Las posibilidades son infinitas!

🐍

¿Qué es Python?

Python es un lenguaje de programación. Es un idioma especial que entiende la computadora. Con Python le decimos a la computadora qué tiene que hacer, paso a paso.

🐍 Python se llama así por un programa de TV muy gracioso que se llamaba Monty Python. ¡No es por la serpiente! Aunque usan una serpiente de símbolo porque es simpático. 😄

💻

¿Qué es el código?

El código son las instrucciones que escribimos para la computadora. Son líneas de texto especiales que la computadora entiende y sigue.

📝 Así como una receta de cocina tiene pasos: "primero mezclá, después horneá"... el código también tiene pasos que la computadora sigue en orden.

📄 Ejemplo de código
mi_primer_codigo.py

2nombre = "Miqueas"
3print("Hola " , nombre)
4# La pantalla muestra: Hola Miqueas

Tipos de datos

Cuando la computadora guarda información, necesita saber qué tipo de información es. ¡Hay tres tipos principales! Toca cada cuadro para escuchar.

💡 ¿Para qué sirven? Los tipos de datos le dicen a Python cómo manejar la información. No es lo mismo guardar una palabra que un número. ¡Python necesita saberlo!

📝

Texto (String)

"Volvo"

🔢

Número entero (Integer)

18

📊

Decimal (Float)

12.5

📄 Ejemplo en VS Code
tipos_de_datos.py
1# String: texto entre comillas
2marca = "Volvo"
3# Integer: número entero sin punto
4ruedas = 18
5# Float: número con punto decimal

Texto → siempre con "comillas"
Número entero → sin punto: 18
Número decimal → con punto: 12.5

Variables

Las variables son como cajitas donde guardamos información. Le ponemos un nombre a cada cajita y adentro guardamos un dato.

💡 ¿Para qué sirven? Guardamos información en una variable para poder usarla después, muchas veces, sin tener que escribirla de nuevo cada vez.

📌 ¿Cómo se escribe una variable?

nombre_cajita = información

El signo = significa "guardá esto ahí adentro"

📄 Ejemplo en VS Code
variables.py
1# Guardamos texto en una variable
2modelo = "FH16"
3# Guardamos un número en otra variable
4ruedas = 18
5print(modelo) # muestra: FH16
6print(ruedas) # muestra: 18

👆 Tocá el ··· para completar el código:

completar.py
1modelo ··· "FH16"
🌟 ¡Genial! El signo = guarda texto en la variable.
completar2.py
1ruedas ··· 18
🌟 ¡Genial! El signo = también guarda números.

Operadores matemáticos

Python puede hacer cuentas matemáticas igual que una calculadora. Estos son los operadores: los símbolos que usamos para hacer cuentas. ¡Toca cada uno para escuchar!

💡 ¿Para qué sirven? Con los operadores le pedimos a Python que haga cuentas por nosotros. ¡Python calcula en un instante, sin importar qué tan difícil sea la cuenta!

+

➕ Suma

Junta dos números y da el total. Por ejemplo, si tenemos 3 camiones y llegan 5 más, en total hay 8.

−

➖ Resta

Le quita un número a otro. Por ejemplo, si teníamos 10 litros de nafta y gastamos 4, quedan 6.

*

✖️ Multiplicar — se escribe con asterisco *

Multiplica dos números. El símbolo en Python es el asterisco (*), no la X. Por ejemplo, 3 * 4 es igual a 12.

/

➗ Dividir — se escribe con barra /

Reparte un número en partes iguales. El símbolo en Python es la barra (/). Por ejemplo, 10 / 2 es igual a 5.

📄 Ejemplos en VS Code
operadores.py
1# Suma (+)
2total = 4 + 6  # resultado: 10
3# Resta (-)
4resta = 10 - 3 # resultado: 7
5# Multiplicar (*) — usamos asterisco
6multi = 3 * 4 # resultado: 12
7# Dividir (/) — usamos barra
8divis = 10 / 2 # resultado: 5.0

Comparaciones

Python puede comparar dos números y decir si es verdadero o falso. ¡Toca cada símbolo para escuchar!

💡 ¿Para qué sirven? Las comparaciones nos ayudan a preguntarle cosas a Python. "¿Este número es mayor?" "¿Son iguales?" Python responde True (verdadero) o False (falso).

True significa Verdadero en inglés. False significa Falso en inglés.

>

Mayor que

<

Menor que

==

Igual a

!= (≠)

Diferente

📌 ¡Importante! = y == son diferentes

= → guarda un valor (una sola vez)
== → pregunta si son iguales (dos veces)
📄 Ejemplos en VS Code
comparaciones.py
19000 > 4000 # True (9000 es mayor)
23 < 10    # True (3 es menor)
35 == 5     # True (son iguales)
46 != 10    # True (son diferentes)
55 == 8     # False (no son iguales)
🚚 Ejemplo con camiones
peso_camion.py
1peso = 9000
2limite = 4000
3print(peso > limite) # muestra: True
4# ¡El camión pesa más que el límite!
